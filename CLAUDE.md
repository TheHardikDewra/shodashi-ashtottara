# Sri Shodashi Ashtottara Shatanama Stotram - Project Context

## What this is
Interactive website for Sri Shodashi Ashtottara Shatanama Stotram - 108 names of Goddess Shodashi (Tripura Sundari) from the Pūrvakhaṇḍa of the Brahmayāmala Tantra.

- Live at https://shodashi-ashtottara.vercel.app
- Repo: https://github.com/TheHardikDewra/shodashi-ashtottara
- Pure vanilla HTML/CSS/JS, no frameworks, no build step
- Data in data.js, generated by build_data.py from sources in ~/shodashi-research/
- This stotra plays as ambient devotion in Lalita Maa Tripura Sundari's "world" inside the Tantra Sadhana app

## Sacred Text - Handle With Care
- Devotional content. Accuracy is non-negotiable.
- Devanagari source: `~/shodashi-research/stotram.txt` and `namavali.txt` (sanskritdocuments.org)
- English meanings: user's own curated translation at `~/Downloads/shodashi-ashtottara-stotram-meanings.md`
- IAST: derived programmatically from Devanagari via Deva→IAST converter in build_data.py
- NEVER fabricate Sanskrit text, transliterations, or meanings

## Structure
- 20 verses total in the stotra:
  - **Verses 1-2**: Framing - Bhṛgu's request (V1) and Brahmā's response (V2)
  - **Verses 3-17**: The 108 names, distributed unevenly across 15 verses
  - **Verses 18-20**: Phalashruti (fruits of recitation)

The 108 names per verse:
- V3: 10, V4: 8, V5: 7, V6: 6, V7: 6, V8: 6, V9: 7, V10: 10
- V11: 8, V12: 7, V13: 6, V14: 10, V15: 8, V16: 5, V17: 4
- Total: 108 ✓

## Source Quirks (handled in build_data.py overrides)
- Namāvalī typo "श्म्भुवनिता" (V20) - should be "Śambhuvanitā" (consort of Shambhu)
- Namāvalī typo "शीग्रसिद्धिदा" (V25) - should be "Śīghrasiddhidā" (swift siddhi)
- Namāvalī "ऋतुरूपा" (V38) vs stotra body "क्रतुरूपा" - the stotra reads Kraturūpā (form of yajña)
- Namāvalī "संज्ञा" (V55) is sandhi-equivalent to user MD's "Sañjñā"
- Namāvalī splits user MD's compound "Bhaktibhāvaparāyaṇā" into V71 + V72
- Namāvalī combines user MD's V16 "Śatacandrānanā" + "Devī" into a single name "Śatacandrānanā Devī" (#100)
- Namāvalī splits user MD's compound "Somasūryāgninayanā" into V102 (Somanayanā) + V103 (Sūryāgninayanā)
- Namāvalī "अर्द्धन्दु" (V105) is a spelling variant of "Ardhendu"

All these are handled by NAMAVALI_MEANING_OVERRIDES in build_data.py.

## Data Pipeline
- Devanagari namāvalī (108 entries) and stotra (20 verses) downloaded from sanskritdocuments.org
- User's IAST + meanings parsed from markdown
- build_data.py converts Devanagari→IAST, normalizes dative→nominative, matches meanings via simplified-IAST keys, applies manual overrides
- Output: data.js with all names, verses, framing translations, phalashruti translations, and per-verse collective meanings

## Design Rules
- NO gradients. NO glowy effects. Solid flat colors only
- NO `linear-gradient`, `radial-gradient`, `box-shadow` glows, `text-shadow` glows
- Fonts: Haffer (local) > Geist > Inter for body; Tiro Devanagari Sanskrit for Sanskrit
- Dark theme default with warm gold accent (#c9a84c) - same as sister projects
- Light / Dark / System theme modes
- Icon: Om (ॐ) in gold, dark background

## File Structure
- `index.html` - Main page, SPA with hash routing (#home, #verses, #names, #practice, #chant)
- `style.css` - All styles. Inherits from sister project (Trishati) base
- `app.js` - Application logic, IIFE wrapped
- `data.js` - Generated data file (DO NOT edit manually)
- `build_data.py` - Data merge script
- `manifest.json` - PWA manifest
- `sw.js` - Service worker for offline support
- `icon.svg` - Om symbol in gold

## Storage Keys (localStorage)
All keys namespaced with `sh_` prefix:
- `sh_learned` - Set of learned name numbers (JSON array)
- `sh_srs` - SM-2 spaced repetition data
- `sh_notes` - User's personal notes per name
- `sh_sadhana` - Sadhana tracker
- `sh_fontsize` - small/normal/large
- `sh_chant_pos` - Last chant verse position
- `sh_chant_settings` - Speed, auto-advance, show translit/meaning
- `sh_theme` - system/light/dark
